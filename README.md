# WADE Fragrances

WADE Fragrances is a modern luxury fragrance storefront and landing page designed to showcase premium scents in a clean, elegant shopping experience. The project highlights signature perfumes with rich visual storytelling, premium product presentation, and a simple browsing flow that makes it easy for customers to explore featured scents and begin shopping.

## Project Description

This project is a polished fragrance brand website built with HTML, CSS, and JavaScript. It includes a luxury-inspired homepage, product-focused sections, and a shopping experience that reflects a premium retail brand. The design emphasizes sophistication, minimalism, and strong visual branding to create a memorable online storefront for fragrance lovers.
